# pi-extension-compact

Estensione Pi in fase di progettazione per la compattazione gerarchica, selettiva e recuperabile del contesto. La specifica iniziale è in [`docs/Progetto_Pi_Context_Compaction_Pipeline_SPEC(1).md`](docs/Progetto_Pi_Context_Compaction_Pipeline_SPEC(1).md).

## Skill degli agenti

Dopo un clone, ricostruisci e verifica le skill fissate nel lock:

```sh
npm run skills:install
npm run skills:verify
```

Per aggiornamenti, rollback e personalizzazioni consulta [`docs/agents/skill-customizations.md`](docs/agents/skill-customizations.md).
