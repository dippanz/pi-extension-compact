**Regole specifiche di `implement`:**
- Non eseguire commit, push, PR o merge: lascia tutte le modifiche non committate nel working tree e fermati prima di questi passi, anche se il testo upstream dice di committare. Li esegue la persona che ti ha incaricato.
- Nel riepilogo finale indica cosa è cambiato, i test e le verifiche eseguiti e, se serve, il comando `git commit` suggerito secondo la sezione "Gestione delle modifiche" di `AGENTS.md`.
- Per la review finale usa `code-review` sulle modifiche non committate (fixed point `HEAD` o quello indicato dall'utente), senza commit preliminari.
